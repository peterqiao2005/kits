# AutoClick 核心防回归规范 (Regression Prevention Rules)

## 1. 严格禁止引入无关副作用 (Zero Side-Effect Principle)
- 任何业务操作按钮（如“📐 还原窗口尺寸”）只能修改其声明的目标对象（模拟器窗口），严禁在函数内夹带调用本窗口（Mini 面板）的 geometry/SetWindowPos 等重定位逻辑。

## 2. 状态层与表现层严格单向同步 (Single Source of Truth)
- UI 控件（如 Combobox 输入框）只是展示层，底层业务（ADB端口、点击驱动、坐标换算）必须唯一依赖真实的 Windows HWND 与 PID。
- 修改任何窗口选择组件时，必须保证：点选/提交输入 -> 立即 100% 同步底层 target_hwnd_var -> 立即重连专属端口。

## 3. 共享组件修改的“全链路依赖自检”（修改前必查）
在修改目标窗口选择、模式切换等全局组件前，必须逐项自查以下 4 条核心依赖链路是否完好：
1. 目标绑定链：下拉选择后，是否底层 HWND 与 ADB 端口同步精准就绪？
2. 模式独立链：主面板与 Mini 面板是否都能独立启动脚本，不需要先在另一面板预启动？
3. 空间边界链：任何涉及窗口位移的操作，必须保证在显示器可见工作区内，严禁产生非法负坐标或被目标遮挡。
4. 异常隔离链：后台子线程必须捕获全量 Exception 并输出至日志，严禁出现 NameError 静默崩溃。
